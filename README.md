# Autotechnology-ShoppingImageAnalyse

手机壳商品名称自动生成工具。

读取带主图的商品表格，用**本地部署的视觉模型**识别图片特征，
按预设规则组装出合规的商品名称，并写回原表格。

---

## 它能做什么

- 读取 Excel 里的商品主图（支持「放置在单元格中」的内嵌图片），逐行生成商品名称
- 名称长度精确可控，支持按平台口径计数（如 1 汉字 = 2 字符）
- 必填词、材质词、违禁词、标点符号全部自动校验
- 同一批次内标题自动差异化，避免雷同
- 写回时完整保留表格内的图片与原有格式

## 设计要点

**硬参数不交给模型。**
材质、系列、适配机型等从商品资料读取，模型只负责「看图能看出来的」——
颜色、图案、风格、图上文字。从架构上杜绝 AI 编造参数。

**配置与代码分离。**
必填词库、材质库、违禁词库、长度规则、组装模板全部走 YAML 配置。
换品类、换平台、换模型只改配置，代码不用动。

**写表安全。**
Excel 写入采用 zip 级定点替换，只改目标单元格，
图片、打印设置等部件原样保留；写前自动备份，写后自动校验。

## 更新说明

### v1.4

**支持多品牌机型，未知品牌自动识别。** 主要变更：

- **一个单元格可混多个品牌**：如 `素皮、iPhoneDuo/小米18Fold/华为PuraXMax/华为puraxmax典藏版`，
  程序**逐个机型单独判品牌**，各品牌的机型都会进标题
- **未知品牌自动识别**：品牌表里没有的品牌（如「小米」）会从机型前缀自动认出，
  用默认模板 `适用{品牌}{机型}` 处理，运行结束给出提示；想自定义写法可加进 `brands`
- **修复未知品牌被改写成苹果**：此前 `小米18Fold` 会被回落成默认品牌苹果并抽数字
  变成 `iPhone18` —— 小米壳的标题写成「适用于苹果18」= **虚假品牌宣称**
- **修复多品牌时后续品牌机型被静默丢弃**：此前整段只判一次品牌，
  判成苹果后 `华为PuraXMax` 会被剥成 `PuraXMax` 再走苹果正则、找不到数字而**静默丢弃**
- **机型段长度优化**：非首个品牌不再重复「适用」前缀，
  4 机型跨 3 品牌从 63 字符降到 **55 字符**（单品牌写法完全不变）
- **长度不够时特征词让位**：固定段太长时按长度降序丢特征词，
  保证必填词 / 机型附加词 / 核心元素进得去（运行时提示丢了哪些）

### v1.3

**修复功能词误加，新增设计元素保证进标题。** 主要变更：

- **修复无支架/挂绳的商品被写上「支架」「带挂绳」** —— 实测模型会把它们当通用功能词输出，
  现改为**只从 A 列判定**；`磁吸` 仍保留图片判定
- **新增核心元素保证**：模型识别出的设计/图案元素（城堡 / 大象 / 米妮头像…）
  每条标题至少出现 1 个（此前被模型词 15% 配额截掉，标题里全是通用词）
- **新增「折叠屏」条件词**：A 列含 `折叠` → `折叠屏` / `阔折叠` / `阔折叠屏` 三选一轮换
- **材质来源补上 D 列**：改为 `A 列 → D 列 → 模型判断`（此前 D 列有材质也会被模型误判覆盖）
- **新增二选一必填词**：`新款` / `2026新款` 按行轮换；**新增机型附加词**（iPhoneDuo → 加 `duo`、`DUO`）
- **新增每类词限量**（精准词每条最多 1 个）；`main_words` 主推词弃用
- 修复 `analyze_composition.py`（此前一直输出 0）

### v1.2

**支持非苹果品牌，修复机型与品牌错误。** 主要变更：

- **品牌按实际机型自动切换**：华为机型生成「适用华为PuraXMax」，不再被套上「苹果」
- **机型解析失败报错跳过**，C 列不写入，绝不编造机型 / 品牌
- **新增「迪士尼联名」条件必含词**：A 列含 `IP联名` 或 `迪士尼` 时自动带上
- **「典藏版」等版本名算独立机型**；单机型也带齐品牌词（苹果 + iPhone）
- **名称彻底禁用空格**，改用换词机制凑满 100 字符；模板槽位不足时自动补足

### v1.1

**更新了名称规则。** 主要变更：

- **适配机型改从表格单独一列读取**（默认 D 列），一行可写多个机型，写法如 `iphone18/17/16/15/14`
- **机型在名称中穿插排布**，与属性词交替出现，不再连成一串；首个机型带「苹果」前缀，第二个带「iPhone」前缀，其后裸写
- **名称中禁止出现任何标点符号**，机型之间也不使用分隔符
- **新增四类运营词库**：主推词 / 搜索词 / 卖点词 / 精准词，按优先级依次取词
- **模型看图特征词占比限制在 15% 以内**，其余位置由运营词库填充
- **新增条件必含词**：识别到磁吸、支架、挂绳等特征时，对应词自动作为固定段插入，不会被长度控制挤掉
- **必填词与违禁词冲突自检**，启动时发现配置矛盾直接报错
