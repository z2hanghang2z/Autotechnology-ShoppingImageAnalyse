# Autotechnology-ShoppingImageAnalyse

手机壳商品名称自动生成工具。

读取带主图的商品表格，用**本地部署的视觉模型**识别图片特征，
按预设规则组装出合规的商品名称，并写回原表格。

---

## 它能做什么

- 读取 Excel 里的商品主图（支持「放置在单元格中」的内嵌图片），逐行生成商品名称
- 名称长度精确可控，支持按平台口径计数（如 1 汉字 = 2 字符）
- 必填词、材质词、违禁词、标点符号全部自动校验
- 同一批次内标题自动差异化，避免雷同
- 写回时完整保留表格内的图片与原有格式

## 设计要点

**硬参数不交给模型。**
材质、系列、适配机型等从商品资料读取，模型只负责「看图能看出来的」——
颜色、图案、风格、图上文字。从架构上杜绝 AI 编造参数。

**配置与代码分离。**
必填词库、材质库、违禁词库、长度规则、组装模板全部走 YAML 配置。
换品类、换平台、换模型只改配置，代码不用动。

**写表安全。**
Excel 写入采用 zip 级定点替换，只改目标单元格，
图片、打印设置等部件原样保留；写前自动备份，写后自动校验。

## 技术栈

`Python` · `Ollama` · `Qwen3.5-VL` · `openpyxl` · `PyYAML`

## 环境要求

- Python 3.11+
- [Ollama](https://ollama.com/) 本地模型服务
- 支持 CUDA / ROCm / Vulkan 的独立显卡
